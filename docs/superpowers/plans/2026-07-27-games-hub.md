# Games Hub Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the direct game setup with a Games menu that launches the renamed Spice Deck and truthfully presents the three upcoming modes.

**Architecture:** Move the current stateful game screen unchanged into `spice-deck.tsx`. Make the index route a stateless menu driven by a typed catalog and one card component. The catalog carries a deliberate availability flag, so a mode cannot become tappable merely because another worker has begun its route.

**Tech Stack:** Expo Router 6, React Native 0.81, React 19, TypeScript, Jest 29, Lucide React Native, existing SpiceSync i18n and theme components.

## Global Constraints

- Preserve Spice Deck rules, content, premium access, persistence schema, timers, sounds, and match-aware deck construction exactly.
- Match Missions, Know Me Better, and Couple Dice remain visible but non-actionable until their routes and tests are complete.
- Add no dependencies, remote sync, analytics, notifications, or storage.
- Localize all user-facing menu copy in English and Spanish; replace visible “Spice Dice” wording with “Spice Deck”.
- Enabled cards use a button role and actionable label; unavailable cards expose disabled state and never receive `onPress`.
- Run focused Jest tests and `npm run lint` from `apps/mobile` before completion.
